## Pulsoid as the Heart Data Source

This mod supports [Pulsoid](https://pulsoid.net/) as a data source. Select Pulsoid in the mod config menu, restart the game, then follow the guide inside the PULSOID menu. Click Open and connect to Pulsoid in your Quest's web browser, then click Done.

You can either enter your token directly or sign into your Pulsoid account. (Special thanks to Pulsoid for providing API support.)

> [!NOTE]
> **PULSOID WITHOUT HEARTBEATQUEST SERVER FORWARD**  
> All heart rate data is obtained directly from the Pulsoid server. However, your token is forwarded through HeartBeatQuest's server on first connection.  
> You can also edit the mod config file directly to skip the token forward. Once configured, the game connects directly to the Pulsoid server — nothing else is forwarded.
