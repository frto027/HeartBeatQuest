# Data Sources

> [!NOTE]
> **DATA SOURCE CONFIG**  
> The settings menu for each data source is on a **DIFFERENT** menu.

> [!NOTE]
> The data sources on this page are sorted alphabetically and are not recommendations. Each has its own advantages, so try them all.

Currently, there are 4 data sources available for this mod:

- **Bluetooth** — pair your heart rate device directly with your Quest. May have less compatibility.
- **HypeRate** and **Pulsoid** — install their app somewhere to get your heart rate and send it to the game. Internet required.
- **OSC** — receive heart data via the OSC protocol.

After changing the data source in the mod config menu, you must **restart your game**.
