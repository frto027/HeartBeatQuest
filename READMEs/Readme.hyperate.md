## HypeRate as the Heart Data Source

This mod supports [HypeRate](https://www.hyperate.io/) as a data source. Install the mod, switch the data source to HypeRate in the settings menu, and restart the game. Enter your HypeRate ID in the HYPE RATE menu and it will work. (Special thanks to HypeRate for providing API support.)

> [!NOTE]
> **ONLINE DATA COLLECTION**  
> This is an online service. Some game information (such as [the version number](https://github.com/frto027/HeartBeatQuest/blob/4243eadcc4062ee619a6606da65a1ba4d50d91c8/src/HBHeartBeatHypeRateDataSource.cpp#L327)) is collected to ensure the service is working properly. This data is only used for error checking and is usually deleted automatically within 3 days. If you'd rather not send this data to the server, use a different data source. If you run into trouble, make sure your Quest can access [this website](https://heart.0xf7.top/).
>
> This mod uses Cloudflare as its fast and reliable backend.
